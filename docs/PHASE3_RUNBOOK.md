# Phase 3 runbook — reproduce the draw engine from a clean checkout

Requirements: Node.js ≥ 22.12 and pnpm 10.34.5. Without a global install, use `npx -y pnpm@10.34.5`
wherever `pnpm` appears below. Docker is needed only for the PostgreSQL 16 database tests.

```bash
git clone https://github.com/marquisccel/bagan-taekwondo.git && cd bagan-taekwondo
pnpm install --frozen-lockfile
pnpm typecheck && pnpm lint && pnpm format:check
pnpm test                      # every tier; REAL_2026 golden tests skip with a notice without private data
```

The 2026 registration file contains personal data of minors and is not in git. Copy it to
`data/private/DATA_KOLEKTIF_FESTIVAL_PRESTASI - query_kolektif.csv`; its SHA-256 is checked, see
`data/README.md`. The synthetic 5K and 10K datasets are generated by the commands themselves.

**Simulate 2026** — golden seed + 20 robustness seeds, committee benchmark:

```bash
pnpm simulate --dataset "data/private/DATA_KOLEKTIF_FESTIVAL_PRESTASI - query_kolektif.csv" \
  --rules fixtures/rulesets/piala-gubernur-2026.provisional.json \
  --baseline fixtures/baselines/committee-2026.json --seeds range:1..20 --out out/simulations
```

**Replay** — 100 golden-seed runs must give one fingerprint:

```bash
pnpm simulate --dataset "data/private/DATA_KOLEKTIF_FESTIVAL_PRESTASI - query_kolektif.csv" \
  --rules fixtures/rulesets/piala-gubernur-2026.provisional.json --replay 100 --out out/simulations
GOLDEN_REPLAY_RUNS=100 pnpm test:golden       # also checks the recorded engine fingerprint
```

**Benchmarks** — machine-readable artifacts; `--readiness DRAW_ELIGIBLE_ONLY` draws every eligible entry:

```bash
pnpm benchmark --name REAL_2026 --dataset "data/private/DATA_KOLEKTIF_FESTIVAL_PRESTASI - query_kolektif.csv" \
  --rules fixtures/rulesets/piala-gubernur-2026.provisional.json --seeds 20260827,1,2 \
  --out docs/reports/phase3-benchmarks/REAL_2026.json
pnpm benchmark --name SYNTHETIC_5K --synthetic 5000 --readiness DRAW_ELIGIBLE_ONLY \
  --rules fixtures/rulesets/piala-gubernur-2026.provisional.json --seeds 20260827,1,2 \
  --out docs/reports/phase3-benchmarks/SYNTHETIC_5K.json
pnpm benchmark --name SYNTHETIC_10K --synthetic 10000 --readiness DRAW_ELIGIBLE_ONLY \
  --rules fixtures/rulesets/piala-gubernur-2026.provisional.json --seeds 20260827 \
  --out docs/reports/phase3-benchmarks/SYNTHETIC_10K.json
```

Each command exits non-zero if a draw is not SAFE or a retry is not identical.

**Database tier on PostgreSQL 16** (PGlite always runs):

```bash
docker compose up -d postgres
DATABASE_URL=postgres://bagantkd:bagantkd_dev_only@127.0.0.1:5433/bagantkd pnpm test:db
```

The engine contract is in `docs/ENGINE_CONTRACT.md`. Calibration and algorithmic decisions are in
`docs/PHASE3_CALIBRATION.md`, and gate evidence in `docs/PHASE3_GATE_REPORT.md`.
